# Systems index

Every living system in the preview corpus, grouped. **Page** links to the per-system reference (written to one shared template: what it is, how it works, glyph coupling, controls and parameters, arc, optics, tiers, Swift/Metal port, gaps, files). All 22 `glab` system pages and 13 `maker` species/kit pages are full references; the remaining 12 `maker` rows link to system note pages generated by `sync.sh` from the clip inventory and script notes.

All systems share the [legibility knob](controls.md) (`legibility` 0..1, `leak = 1 − legibility`) and the [GlyphSource](glyph-source.md) products. The [optics page](systems/glab/optics.md) is the shared post-stack reference.
